# Models folder

Generated by the build:
* `chaseiq_win_model.joblib` — selected win-probability model (scikit-learn pipeline).
* `evaluation.json` — held-out test metrics, baselines, calibration and feature importance.
* `simulator_validation.json` — strategy simulator checked against realised historical outcomes.

These are regenerated with `python app.py --build`. The model is trained only on the uploaded data.
